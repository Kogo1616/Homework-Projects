# 💊 PharmaPrice

აპლიკაცია, რომელიც აჩვენებს თუ რომელ აფთიაქშია წამალი ყველაზე იაფად —
**რეალური, ცოცხალი ფასებით**.

## რომელი აფთიაქებია ინტეგრირებული

| აფთიაქი | წყარო | სტატუსი |
|---|---|---|
| **PSP** | Magento GraphQL API (`app.psp.ge/graphql`) | ✅ რეალური |
| **GPC** | Next.js embedded JSON (`gpc.ge`) | ✅ რეალური |
| **ფარმადეპო** | Next.js embedded JSON (`pharmadepot.ge`) | ✅ რეალური |
| ავერსი | — | ⏳ შემდეგ ეტაპზე |
| იმპექსი | — | ⏳ შემდეგ ეტაპზე |

მომხმარებელი ეძებს წამალს → backend ერთდროულად ეკითხება ყველა აფთიაქს →
აბრუნებს ყველა შეთავაზებას, დალაგებულს იაფიდან, ყველაზე იაფის მონიშვნით.

## სტრუქტურა (ერთი deploy)

```
PharmaPrice/
├── backend/                → ASP.NET Core (.NET 10)
│   ├── Providers/          → თითო აფთიაქზე ერთი კლასი
│   │   ├── IPharmacyPriceProvider.cs
│   │   ├── PspProvider.cs      (GraphQL)
│   │   └── GephaProvider.cs    (GPC + ფარმადეპო)
│   ├── Services/
│   │   └── PriceSearchService.cs  (აგრეგაცია + ქეში)
│   └── Program.cs
├── frontend/               → React + Vite
└── PharmaPrice.sln
```

`dotnet publish` **ორივეს ერთად** აწყობს: React ავტომატურად შენდება და
backend-ის `wwwroot`-ში ხვდება. ერთი აპლიკაცია, ერთი პორტი, ერთი deploy.

## გაშვება (development)

ორი ტერმინალი:

```bash
cd backend && dotnet run
```
```bash
cd frontend && npm run dev
```
ბრაუზერში: http://localhost:5173

## Production (ერთი აპლიკაცია)

```bash
cd backend && dotnet publish -c Release -o ../publish
cd ../publish && ./backend.exe
```
ყველაფერი (frontend + API) ერთ პორტზე გაეშვება.

## ახალი აფთიაქის დამატება

1. დაწერე ახალი კლასი, რომელიც `IPharmacyPriceProvider`-ს ახორციელებს.
2. დაარეგისტრირე `Program.cs`-ში.
3. სულ ეს არის — `PriceSearchService` ავტომატურად ჩართავს ძებნაში.

## ძებნა როგორ მუშაობს

1. **რელევანტობის ფილტრი** — მოთხოვნის სიტყვები (მაგ. "მიგ") რეალურად უნდა
   გვხვდებოდეს პროდუქტში. ეს აშორებს ხმაურს (მაგ. "მიგ 400"-ზე "400 მლ" შამპუნებს).
2. **დაჯგუფება** — ერთი და იგივე წამალი სხვადასხვა აფთიაქიდან ერთ ბარათად
   ერთიანდება, გვერდიგვერდ ფასებით და ყველაზე იაფის მონიშვნით.
   ლოგიკა: `Services/MedicineMatcher.cs`.

## API

| Endpoint | აღწერა |
|---|---|
| `GET /api/search?q=<სახელი>` | დაჯგუფებული წამლები, თითო რამდენიმე აფთიაქის ფასით, დალაგებული იაფიდან |
| `GET /api/pharmacies` | ინტეგრირებული აფთიაქების სია |
